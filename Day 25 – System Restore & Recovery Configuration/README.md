# Day 25 – System Restore & Recovery Configuration

This lab focuses on configuring and verifying Windows System Restore to support system recovery and rollback in the event of failed updates, misconfigurations, or software issues.

---

## Tasks Completed

- Verified System Protection status on the system drive
- Enabled System Restore for Local Disk (C:)
- Configured disk space usage for restore points
- Created a manual restore point prior to system changes
- Confirmed restore point creation and availability

---

## Tools Used

- Windows 11
- System Properties
- System Protection (System Restore)
