## Day 11 – User Account Permissions & UAC (Least Privilege)

This lab focuses on managing user permissions and enforcing the principle of least privilege using standard and administrator accounts in Windows 11.

---

### Tasks Completed
- Reviewed local user account types
- Verified administrator and standard user roles
- Tested restricted actions under a standard user context
- Observed User Account Control (UAC) elevation prompts
- Reviewed UAC security settings

---

### Tools Used
- Windows 11
- User Accounts
- User Account Control (UAC)

### Skills Demonstrated

- User permission management
