# Day 15 – Disk Management & Volume Configuration

This lab focuses on using Disk Management to review disk layout and perform basic volume management tasks commonly handled by IT support technicians.

## Tasks Completed
- Opened Disk Management to review system disk configuration
- Identified available disk space and partitions
- Reviewed volume layout and disk capacity
- Accessed volume management options
- Verified disk status and health

## Tools Used
- Windows 11
- Disk Management (diskmgmt.msc)

## Skills Demonstrated
- Disk and volume management
- Storage troubleshooting fundamentals
- System resource analysis
- Windows administrative tools
