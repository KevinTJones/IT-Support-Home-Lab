## Day 13 – Device Manager & Driver Troubleshooting

This lab focuses on identifying hardware devices, reviewing driver status, and validating proper device functionality using Device Manager.

- Inspected device properties and driver status

- Confirmed successful device recovery

- Device Manager

### Skills Demonstrated

- Driver verification
- Device status analysis
- Safe troubleshooting practices
- End-user support workflows
