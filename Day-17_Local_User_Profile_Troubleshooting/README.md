# Day 17 – Local User Profile Troubleshooting

This lab focuses on diagnosing and resolving common Windows user profile issues
that prevent successful logins or cause temporary profile behavior.

## Tasks Completed
- Reviewed configured local user accounts
- Inspected user profile folder structure
- Simulated a profile loading issue
- Observed login behavior with a mismatched profile
- Restored proper user profile access

## Tools Used
- Windows 11 Settings
- File Explorer
- Local User Accounts

## Skills Demonstrated
- User profile troubleshooting
- Access and permissions awareness
- Windows account recovery
- End-user support workflows
