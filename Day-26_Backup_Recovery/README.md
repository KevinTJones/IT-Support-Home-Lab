# Day 26 – Backup & Recovery (Windows Backup / OneDrive)

This lab focuses on verifying backup and recovery configuration in Windows 11. The objective is to confirm how user data, system settings, and application preferences are protected using Windows Backup with OneDrive integration.

## Tasks Completed
- Reviewed Windows Backup configuration settings
- Verified OneDrive-based file backup status
- Confirmed backup of user folders, including Desktop, Documents, and Pictures
- Verified app list and system preferences backup
- Identifiedthe  last successful backup timestamp
- Documented the absence of traditional File History in favor of cloud-based backup

## Tools Used
- Windows 11
- Windows Backup
- OneDrive

## Key Findings
- Windows Backup is enabled and active
- User files are protected through OneDrive synchronization
- Application list and system preferences are backed up to the Microsoft account
- Traditional File History is not enabled on this system
- The system follows Windows 11’s default cloud-first backup strategy

## Skills Demonstrated
- Backup and recovery verification
- Windows 11 system configuration analysis
- Cloud-based data protection awareness
- Preventive maintenance validation
- IT support documentation practices

## Evidence
Screenshots captured showing:
- Windows Backup status via Microsoft account
- OneDrive folder synchronization enabled
- App list and preferences included in backup
- Last successful backup confirmation

Backup is configured using Windows Backup with OneDrive synchronization. Traditional File History is not enabled on this device, which aligns with Windows 11’s default cloud-based backup approach.

## Outcome
System backup configuration verified successfully. No remediation required.
