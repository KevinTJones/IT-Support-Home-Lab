# Day 24 – Windows Update Management

This lab focuses on reviewing and validating Windows Update status, update history, and advanced update configuration settings to ensure the system is properly maintained and compliant with update best practices.

## Tasks Completed
- Verified current Windows Update status
- Reviewed installed update history
- Checked advanced Windows Update configuration settings
- Confirmed active hours and restart behavior

## Tools Used
- Windows 11
- Windows Update Settings

## Skills Demonstrated
- Patch management awareness
- System maintenance verification
- Update configuration review
- End-user impact consideration (active hours)

- Windows Update status
